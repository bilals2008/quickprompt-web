# ⚡ QuickPrompt

A fast, private prompt manager — save, search, and reuse prompts instantly.

## 🚀 Features

- ⚡ **Instant Save** — floating action button to save prompts in one click
- 📋 **One-Click Copy** — copy any prompt to clipboard instantly
- 🔍 **Full-Text Search** — find prompts across all tags and content
- 🎨 **Themes** — Light, Dark, Forest, Ocean
- ⌨️ **Keyboard-First** — navigate without touching the mouse
- ⭐ **Favorites** — star your most-used prompts
- 🏷️ **Smart Tags** — organize with tags and autocomplete
- 🚀 **Blazing Fast** — Electron + SQLite, launches instantly

## 📦 Tech Stack

| Layer | Tech |
|-------|------|
| Framework | React 19 + Vite 8 |
| Styling | Tailwind CSS v4 |
| Animations | GSAP + ScrollTrigger |
| Icons | Tabler Icons |

## 🛠️ Getting Started

```bash
git clone https://github.com/bilals2008/quickprompt-web.git
cd quickprompt-web
npm install
npm run dev
```
